# BUILD_GUIDE.md — как запустить и собрать QuizMaster

Подробная пошаговая инструкция: **[docs/BUILD_GUIDE.md](docs/BUILD_GUIDE.md)**.

Этот файл — короткая шпаргалка «что нажимать». Всё выполняется в папке проекта
(там, где лежат `INSTALL.bat`, `START.bat`, `BUILD.bat`, `package.json` и папка `packs`).

## 1. Один раз установите Node.js

1. Откройте `https://nodejs.org`.
2. Нажмите кнопку **LTS** и установите скачанный файл, нажимая «Далее» без изменений.
3. Проверка: `Win+R` → `cmd` → `Enter`, затем команды `node -v` и `npm -v`.
   Должны появиться номера версий (например `v24.21.0` и `11.19.0`).

## 2. Установите зависимости проекта

Дважды щёлкните **`INSTALL.bat`**. Нужен интернет, займёт 3–10 минут.
В конце появится «Готово! Зависимости установлены. Теперь запускайте START.bat».

## 3. Запустите приложение

Дважды щёлкните **`START.bat`**. Появятся строки «Собираю приложение…» и «Запускаю QuizMaster…»,
затем откроется окно «QuizMaster — редактор».

- Если нужен режим разработки (изменения интерфейса применяются на лету) — **`START-DEV.bat`**.
- Окно консоли, которое открылось, не закрывайте: вместе с ним закроется приложение.

## 4. Соберите установщик Windows

Дважды щёлкните **`BUILD.bat`**. Нужен интернет и около 1,5 ГБ свободного места;
первая сборка занимает 5–10 минут.

Готовый файл появится в папке `release`:

```
release\QuizMaster-1.3.0-Setup.exe
```

Его можно перенести на другой компьютер и установить там — Node.js и интернет
на этом компьютере не нужны.

## 5. Установите и проверьте

1. Запустите `release\QuizMaster-1.3.0-Setup.exe` — установка пройдёт сама за несколько секунд
   (для текущего пользователя, без прав администратора), приложение запустится автоматически.
   Запасной вариант без установки: распаковать `release\QuizMaster-1.3.0-portable.zip`
   в любую папку и запустить `QuizMaster.exe`.
2. Запустите QuizMaster с рабочего стола или из меню «Пуск».
3. Откроется окно редактора. Слева панель «Раунды», сверху кнопки
   «Новый / Открыть / Сохранить как / Сохранить / ▶ Провести игру».
4. Быстрая проверка: «Демо-паки» → «Открыть» (Демо-квиз: Космос) → «▶ Провести игру».
   Должны открыться панель ведущего и игровой экран.

Если что-то пошло не так — таблица типовых ошибок: [docs/troubleshooting.md](docs/troubleshooting.md).
Перенос проекта на другой компьютер: [docs/TRANSFER_GUIDE.md](docs/TRANSFER_GUIDE.md).
