# QuizMaster: инструкция по работе с приложением

Это подробное руководство по всем действиям в приложении. Если вы впервые запускаете
QuizMaster, начните с [README.md](../README.md) и [docs/BUILD_GUIDE.md](BUILD_GUIDE.md),
а затем возвращайтесь сюда.

## 1. Что открывается при запуске

После запуска (`START.bat` или ярлык установленной версии) открывается окно
«QuizMaster — редактор». Это стартовое окно приложения: в нём создаются паки и из него
запускается игра.

Окна приложения:

| Окно | Как открыть | Для чего |
|---|---|---|
| редактор паков | открывается при запуске приложения | создание и сохранение паков |
| панель ведущего | кнопка «▶ Провести игру» в редакторе | управление игрой и внесение баллов |
| игровой экран | кнопка «▶ Провести игру» в редакторе | показ игры участникам; обычно на втором мониторе или проекторе |

Повторный запуск приложения при уже работающем экземпляре новых окон не создаёт: приложение
выводит на передний план окно редактора, если оно открыто.

## 2. Редактор паков

### 2.1. Новый пак

1. Нажмите «Новый» в верхней панели или Ctrl+N.
2. Если в текущем паке есть несохранённые изменения, появится вопрос «Создать новый пак?» —
   нажмите «Создать», если изменения не нужны.

Ожидаемый результат: появляется пак «Новый квиз» с одним раундом и одним пустым вопросом.

### 2.2. Открыть пак

1. Нажмите «Открыть» (Ctrl+O).
2. В диалоге выберите файл `.quizpack`. Диалог изначально открывается в папке с демо-паками.

Ожидаемый результат: пак загружен, внизу появляется сообщение «Пак открыт». Если в паке
проблемы с медиа, появится сообщение «Пак открыт с замечаниями» и список замечаний.

Демонстрационные паки:

1. Нажмите «Демо-паки» в левой панели.
2. В списке выберите пак и нажмите «Открыть».

В проекте есть два демо-пака: «Демо-квиз: Быстрый старт» (1 раунд, 3 вопроса) и
«Демо-квиз: Космос» (2 раунда, 5 вопросов, изображение и аудио).

### 2.3. Сохранить пак

| Действие | Как | Результат |
|---|---|---|
| сохранить в текущий файл | «Сохранить» или Ctrl+S | пак записывается в открытый файл; если файла ещё нет, откроется диалог сохранения |
| сохранить копию | «Сохранить как» или Ctrl+Shift+S | откроется диалог, пак записывается в новый файл |

1. При сохранении в новый файл выберите папку и имя файла. По умолчанию диалог предлагает
   папку «Документы» и имя по названию пака. Расширение `.quizpack` добавляется автоматически.
2. Нажмите «Сохранить».

Ожидаемый результат: сообщение «Пак сохранён», в верхней панели — отметка «Сохранено»
и имя файла.

Если появилось «Пак сохранён с замечаниями» — чаще всего не хватает файла медиа:
такой файл не попадёт в пак. Замечания перечислены в сообщении.

### 2.4. Автосохранение черновика

Изменения автоматически записываются в черновик примерно через секунду после последнего
изменения. В верхней панели при этом видна отметка «Не сохранено» и время черновика.

Если приложение закрылось аварийно, при следующем запуске:

1. Редактор загрузит последний черновик.
2. Появится полоса «Восстановлен несохранённый черновик от …».
3. Проверьте содержимое и нажмите «Сохранить», чтобы записать пак в файл.

Кнопка «Скрыть» убирает полосу. Успешное сохранение пака очищает черновик.

### 2.5. Настройки пака

1. Нажмите «⚙ Настройки пака» в левой панели.
2. Заполните поля:
   - «Название игры» — крупный заголовок на игровом экране;
   - «Описание» — текст под заголовком, показывается перед началом игры;
   - «Время по умолчанию, сек» — значение для новых вопросов (по умолчанию 60);
   - «Баллы по умолчанию» — стоимость для новых вопросов (по умолчанию 1).
3. Выберите тему оформления в блоке «Тема оформления» (необязательно).
4. Нажмите «Применить».

Ожидаемый результат: новые раунды и вопросы создаются с указанными значениями,
а игровой экран оформляется выбранной темой. Название пака также можно изменить
прямо в верхней строке редактора.

Темы оформления:

Тема меняет только игровой экран — то, что видят участники на проекторе или втором мониторе.
Редактор паков и панель ведущего всегда остаются в своей тёмной теме. Тема не влияет
на вопросы, сценарий, баллы и статистику.

В окне настроек темы сгруппированы по разделам. Над списком тем показан предпросмотр игрового
экрана: при выборе темы он сразу обновляется.

| Раздел | Темы |
|---|---|
| «Базовые» | «Студия» (по умолчанию), «Голубая», «Розовая», «Пастель» — светлая пастельная |
| «Сезоны» | «Зима», «Весна», «Лето», «Осень» |
| «Стили» | «Киберпанк», «Ретро (XP)» — в стиле Windows XP, «Windows 98» — в стиле Windows 98 |
| «Праздники» | «Хэллоуин», «Новый год», «День святого Валентина» |

Выбранная тема сохраняется в паке `.quizpack`. Старые паки без темы открываются со «Студией».

### 2.6. Раунды

| Действие | Как |
|---|---|
| добавить раунд | кнопка «+ Раунд» в панели «Раунды» |
| выбрать раунд | щёлкнуть по раунду в списке |
| переименовать раунд | изменить текст в поле над списком вопросов |
| изменить порядок | кнопки ↑ и ↓ у раунда в списке |
| удалить раунд | кнопка ✕ у раунда, затем подтвердить |

Ожидаемый результат: раунды в списке слева и в панели вопросов соответствуют изменениям.

Ограничение: в паке всегда остаётся хотя бы один раунд. При попытке удалить последний
появится сообщение «В паке должен остаться хотя бы один раунд».

### 2.7. Вопросы

| Действие | Как |
|---|---|
| добавить вопрос | кнопка «+ Вопрос» в панели вопросов |
| выбрать вопрос | щёлкнуть по вопросу в списке |
| изменить порядок | кнопки ↑ и ↓ в нижней части панели вопросов (или в шапке редактора вопроса) |
| дублировать | кнопка «⧉» в панели вопросов или «Дублировать» в шапке |
| скопировать в другой раунд | кнопка «📋» или «В другой раунд» |
| удалить | кнопка «✕» или «Удалить» в шапке, затем подтвердить |

Копирование в другой раунд:

1. Нажмите «📋» (или «В другой раунд»).
2. В окне «Скопировать вопрос в другой раунд» выберите раунд.
3. Нажмите «Скопировать».

Ожидаемый результат: копия появляется в конце выбранного раунда, оригинал не меняется.
Текущий раунд в списке недоступен для выбора — для копии в том же раунде используйте
«Дублировать».

Поля вопроса:

| Поле | Что заполнять |
|---|---|
| «Текст вопроса» | вопрос крупным текстом; его увидят участники |
| «Время ответа, секунд» | от 5 до 3600 секунд; по умолчанию 60 |
| «Стоимость ответа, баллов» | от 0 до 1000; дробные значения разрешены, например 2,5 |
| «Правильный ответ» | эталонный ответ для ведущего; на игровом экране появляется по кнопке «Показать ответ» |
| «Пояснение (необязательно)» | показывается после раскрытия ответа |
| «Изображение», «Аудио», «Видео» | медиафайлы вопроса (см. ниже) |

Если в раунде остался один вопрос, кнопка удаления не удаляет его, а очищает: появится
вопрос «Очистить вопрос?». Так раунд не остаётся пустым.

### 2.8. Медиа вопроса

Для каждого вопроса можно добавить изображение, аудио и видео — по одному файлу каждого типа.

Добавление:

1. В блоке «Изображение», «Аудио» или «Видео» нажмите «Добавить» (или щёлкните по пустому блоку).
2. В диалоге выберите файл.

Ожидаемый результат: файл скопирован в медиатеку приложения, в блоке появился предпросмотр
и имя файла с размером.

Поддерживаемые расширения:

| Тип | Расширения |
|---|---|
| изображение | PNG, JPG, JPEG, WEBP, GIF, BMP |
| аудио | MP3, WAV, OGG, M4A, FLAC, AAC |
| видео | MP4, WEBM, MOV, MKV, M4V |

Для надёжного воспроизведения используйте MP4/WEBM для видео и MP3/WAV для звука:
остальные форматы зависят от кодеков, встроенных в приложение.

Предпросмотр:

- изображение показывается сразу;
- аудио: кнопка ▶/❚❚, перемотка полосой, время, кнопка 🔁 включает повтор;
- видео: обычные элементы управления, кнопка «Повторять» включает повтор.

Замена и удаление:

- «Заменить» — выбрать другой файл вместо текущего;
- «Удалить» — убрать медиа из вопроса (файл остаётся в медиатеке приложения).

Один и тот же файл, добавленный в разные вопросы, хранится в паке один раз.

### 2.9. Проверка пака перед игрой

При нажатии «▶ Провести игру» приложение проверяет пак:

| Проверка | Результат |
|---|---|
| в паке нет раундов или вопросов | игра не запускается, появляется сообщение «Нельзя начать игру» |
| у части вопросов пустой текст или правильный ответ | игра запускается, появляется предупреждение «Игра запускается, но проверьте пак» |

Если пак ещё не сохранён или есть изменения, перед запуском игры приложение сохраняет файл
(может открыться диалог сохранения). Если сохранение отменить, игра не запустится.

### 2.10. Горячие клавиши редактора

| Клавиши | Действие |
|---|---|
| Ctrl+S | сохранить пак |
| Ctrl+Shift+S | сохранить копию |
| Ctrl+O | открыть пак |
| Ctrl+N | новый пак |
| Ctrl+Enter | провести игру |

## 3. Запуск игры и игровой экран

1. В редакторе нажмите «▶ Провести игру» (Ctrl+Enter).
2. Дождитесь двух новых окон: «QuizMaster — панель ведущего» и «QuizMaster — игровой экран».

Ожидаемый результат: панель ведущего показывает лобби с названием пака, а на игровом экране
появляется заставка с названием игры и надписью «Ожидание начала игры». Игровой экран
оформлен в теме, выбранной в настройках пака (раздел 2.5); редактор и панель ведущего
тему не меняют.

Как выбирается монитор:

- если к компьютеру подключено два монитора, игровое окно открывается на втором и сразу
  в полноэкранном режиме;
- если монитор один, игровое окно открывается на нём;
- монитор можно выбрать и сменить в панели ведущего в лобби, блок «Экраны».

Кнопки управления игровым окном (в панели ведущего):

| Кнопка | Действие |
|---|---|
| «Открыть игровое окно» | открыть игровое окно или вывести его на передний план |
| «Закрыть игровое окно» | закрыть игровое окно (игра при этом продолжается) |
| «Полный экран» / «Оконный режим» | переключить полноэкранный режим |

На игровом экране клавиша F11 переключает полный экран. Клавиша Esc игровое окно
не закрывает. При движении мыши в углу ненадолго появляется подсказка «F11 полный экран».

## 4. Лобби в панели ведущего

Лобби открывается сразу после запуска игры — до нажатия «Начать игру». Если игра была
прервана, после восстановления открывается та фаза, на которой она остановилась.

### 4.1. Режим игры

1. В блоке «Команды» выберите переключатель «Команды» или «Индивидуальные участники».
2. Выбор применяется после нажатия «Начать игру».

Режим влияет на подписи в интерфейсе («Команды» или «Участники»). После начала игры режим
фиксируется до её завершения: для игры в другом режиме запустите новую игру из редактора
или нажмите «Сбросить игру» на экране итогов.

### 4.2. Состав участников

| Действие | Как |
|---|---|
| добавить | введите название в поле и нажмите «Добавить» или Enter |
| переименовать | щёлкните по названию в списке, введите новое и нажмите Enter (или щёлкните вне поля) |
| удалить | кнопка ✕ справа от названия |

Ожидаемый результат: список обновляется сразу, счётчик в заголовке показывает число
участников.

Ограничения: не больше 40 участников; название — до 60 символов; пустое название
не добавляется.

Пока игра не начата, список можно менять свободно. После нажатия «Начать игру» состав
фиксируется до конца игры.

### 4.3. Экраны

1. В блоке «Экраны» выберите монитор в списке.
2. При необходимости нажмите «Открыть игровое окно» и включите переключатель «Полный экран».

Ожидаемый результат: игровое окно открывается на выбранном мониторе.

### 4.4. Начать игру

1. Убедитесь, что добавлен хотя бы один участник и игровое окно открыто на нужном мониторе.
2. Нажмите «Начать игру».

Ожидаемый результат: на игровом экране появляется заставка первого раунда, в панели
ведущего — карточка раунда с кнопкой «Начать раунд →». Игра начинается с раунда 1.

Кнопка «Начать игру» недоступна, пока не добавлен ни один участник.

## 5. Ход игры

### 5.1. Заставка раунда

На игровом экране показывается название раунда. В панели ведущего доступны:

- «Начать раунд →» — открыть первый вопрос раунда;
- «Завершить раунд» — сразу перейти к внесению результатов (с подтверждением).

Ожидаемый результат после «Начать раунд →»: открывается вопрос, таймер запускается
автоматически.

### 5.2. Вопрос и таймер

При открытии вопроса таймер запускается сам и отсчитывает время, указанное для вопроса.
Остаток виден крупно в панели ведущего и на игровом экране.

В карточке вопроса в панели ведущего правильный ответ виден всегда, участникам он
не показывается до нажатия «Показать ответ».

Что происходит, когда время вышло: таймер показывает 00:00, на игровом экране появляется
надпись «Время вышло». Вопрос при этом не переключается — следующий открывает ведущий
кнопкой «Следующий →».

### 5.3. Кнопки управления вопросом

| Кнопка | Действие |
|---|---|
| «Следующий →» | открыть следующий вопрос; на последнем вопросе — завершить раунд |
| «Завершить раунд →» | то же, что «Следующий →», когда вопрос последний |
| «← Назад» | вернуться к предыдущему вопросу; с первого вопроса — к заставке раунда |
| «Пропустить» | отметить вопрос пропущенным и перейти к следующему |
| «Завершить раунд» | завершить раунд досрочно (с подтверждением, если вопросы остались) |

При переходе к другому вопросу таймер начинается заново, а медиа вопроса воспроизводится
с начала.

Пропуск вопроса:

1. Нажмите «Пропустить».
2. Подтвердите действие.

Ожидаемый результат: вопрос помечается «пропущен» в таблице баллов и не участвует
в статистике вопросов и наградах.

### 5.4. Пауза

| Действие | Как |
|---|---|
| поставить на паузу | кнопка «Пауза» |
| продолжить | кнопка «Продолжить» |

Что происходит: таймер останавливается, на игровом экране появляется надпись «Пауза»,
видео и аудио приостанавливаются. После снятия паузы отсчёт продолжается с того же остатка,
медиа продолжает играть с того же места.

### 5.5. Показ правильного ответа

1. Нажмите «Показать ответ» в верхней панели.
2. На игровом экране появится блок «Правильный ответ» со стоимостью вопроса и пояснением,
   если оно заполнено.

Важно: показ ответа останавливает таймер. Чтобы вернуть отсчёт времени, нажмите «Пауза»,
затем «Продолжить». Скрытие ответа само таймер не запускает. Кнопка «Скрыть ответ» убирает
ответ с игрового экрана.

### 5.6. Что видно на игровом экране

| Элемент | Описание |
|---|---|
| название раунда | в верхней части |
| «Вопрос N из M» | счётчик вопросов раунда |
| стоимость вопроса | отмечена звездой |
| таймер | крупный круговой отсчёт |
| текст вопроса | крупно, размер подбирается автоматически |
| медиа | изображение, видео или аудиоплеер вопроса |
| правильный ответ | только после нажатия «Показать ответ» |

Медиа в игре:

- **изображение** показывается в медиа-зоне вопроса;
- **видео** запускается автоматически, у него есть встроенные элементы управления;
- **аудио** показывается отдельным плеером: кнопка ▶/❚❚, перемотка, время, кнопка повтора;
- если у вопроса указаны и видео, и изображение, показывается видео;
- пауза игры останавливает медиа, продолжение возобновляет его.

## 6. Внесение баллов

### 6.1. Таблица баллов

В центре панели ведущего находится таблица раунда: строки — вопросы, столбцы — участники.
Внизу строки «Итого за раунд».

1. Щёлкните по ячейке на пересечении вопроса и участника.
2. В нижней части панели появится блок быстрого ввода баллов для этой ячейки.

Незаполненная ячейка показывает «—». Внесённые баллы отображаются числом.

### 6.2. Быстрый ввод

| Кнопка | Что ставит |
|---|---|
| «Верно · X» | полную стоимость вопроса |
| «Частично · X» | половину стоимости вопроса (50%) |
| «Неверно · 0» | 0 баллов |
| «Применить» | число из поля ввода |
| «+1» | прибавить 1 балл к текущему значению |
| «−1» | вычесть 1 балл |
| «Сброс» | поставить 0 |

Произвольное значение: введите число в поле (можно с запятой или точкой: `2,5` или `2.5`)
и нажмите «Применить» или Enter.

Ожидаемый результат: значение сразу появляется в ячейке, в панели «Общий счёт» справа
пересчитываются места, шкала «Внесено … из … оценок» заполняется.

Правила:

- баллы не могут быть отрицательными: при вводе отрицательного числа появится сообщение
  «Баллы не могут быть отрицательными»;
- дробные баллы разрешены, сохраняется до трёх знаков после запятой;
- «Частично» всегда даёт ровно половину стоимости вопроса;
- «−1» не делает значение отрицательным: на нуле оно остаётся нулём.

### 6.3. Правка баллов других раундов

1. В строке «Раунды» над таблицей выберите нужный раунд.
2. Внесите или исправьте баллы.
3. Вернитесь к текущему раунду кнопкой «К текущему раунду».

Пока открыт другой раунд, рядом с прогрессом видна отметка «Раунд N — редактирование».

### 6.4. Итоговый счёт

Панель «Общий счёт» справа показывает места, названия и суммы баллов всех участников.
Лидер отмечен значком. Счёт пересчитывается после каждого изменения.

## 7. Завершение раунда и итоги игры

### 7.1. Итоги раунда

Раунд завершается после последнего вопроса: нажмите «Завершить раунд →» в карточке вопроса
или «Завершить раунд» в панели — откроется экран «Раунд завершён — внесите результаты».
Завершить раунд можно и досрочно, с подтверждением.

На этом экране:

- слева — «Итоги раунда»: места и суммы баллов за раунд;
- в центре — та же таблица баллов; её можно править;
- справа — «Общий счёт».

Внизу слева — кнопки:

| Ситуация | Кнопки |
|---|---|
| раунд не последний | «Следующий раунд», «Итоги игры» |
| раунд последний | «Показать итоги» |

Ожидаемый результат: «Следующий раунд» открывает заставку следующего раунда, «Итоги игры»
и «Показать итоги» открывают финальный экран.

На игровом экране в это время показывается «Раунд завершён» и надпись «Ждём ведущего»;
баллы участникам не показываются.

### 7.2. Итоги игры

Финальный экран в панели ведущего содержит:

| Блок | Что показывает |
|---|---|
| «Итоговая таблица» | место, участник, баллы по раундам (Р1, Р2, …), итог |
| «Победитель» | лучший результат или «ничья по сумме баллов» |
| «Самый лёгкий вопрос» | вопрос с наибольшим числом полных ответов |
| «Самый сложный вопрос» | вопрос с наименьшим числом полных ответов |
| «Награды» | «Единственные знатоки», «Без ошибок», «Серия побед», «Рывок» — если условия выполнены |
| «Серии» | самые длинные серии полных ответов подряд |

Кнопки в верхней панели:

| Кнопка | Действие |
|---|---|
| «Новая игра» | открывает редактор, чтобы выбрать или создать другой пак |
| «Игровой экран» | выводит игровое окно |
| «Сбросить игру» | закрывает текущую игру после подтверждения; результаты теряются |

Победитель определяется по сумме баллов. Если у нескольких участников одинаковый лучший
результат, на игровом экране показываются «Ничья» и «Все молодцы!», а в панели ведущего —
«ничья по сумме баллов». Если все участники без баллов, панель ведущего сообщает
«Победитель не определён».

На игровом экране показываются победитель или «Ничья» с надписью «Все молодцы!», подиум,
итоговая таблица и награды.

## 8. Восстановление прерванной игры

Приложение сохраняет незавершённую игру автоматически: после каждого изменения и во время
работы таймера (примерно раз в 3 секунды). Файл сохранения —
`%APPDATA%\quizmaster\sessions\current.json`.

Когда восстановление доступно: если игра была прервана (закрыто приложение, закрыто окно
консоли, сбой питания) в фазе заставки раунда, вопроса или итогов раунда.

Как восстановить:

1. Запустите QuizMaster (`START.bat` или ярлык установленной версии).
2. В редакторе откройте пак, которым играли (кнопка «Открыть»), и нажмите «▶ Провести игру» —
   откроется панель ведущего. Если редактор предложит сохранить пак, сохраните его: это нужно
   только для открытия панели ведущего, сохранённая игра берётся из отдельного файла.
3. В панели появится полоса «Найдена незавершённая игра» с названием пака, номером раунда
   и вопроса, временем сохранения и списком участников.
4. Нажмите «Восстановить».

Ожидаемый результат: открывается панель ведущего на том же раунде и вопросе, игровой экран
показывает тот же вопрос. Баллы, участники, пропущенные вопросы и остаток таймера сохраняются
(остаток может отличаться на пару секунд).

Если восстановление попало на вопрос или заставку раунда, игра стоит на паузе: нажмите
«Продолжить», чтобы запустить отсчёт. Если восстановление попало на экран итогов раунда,
пауза не показывается — сразу вносите баллы.

Кнопка «Удалить» в полосе стирает сохранение: восстановить эту игру больше нельзя.

Когда восстановление недоступно:

- игра была в лобби — сохранять нечего, участники вводятся заново;
- игра уже завершена — сохранение удаляется автоматически после показа итогов;
- файл сохранения удалён вручную или очищена папка данных.

## 9. Данные приложения

| Папка | Содержимое |
|---|---|
| `%APPDATA%\quizmaster\media` | медиатека: файлы изображений, аудио и видео, добавленные в паки |
| `%APPDATA%\quizmaster\drafts` | черновик редактора (`draft.json`) |
| `%APPDATA%\quizmaster\sessions` | сохранение незавершённой игры (`current.json`) |

Открыть папку данных: меню приложения «Справка» → «Открыть папку данных».

Важно:

- паки `.quizpack` хранятся отдельными файлами там, где вы их сохранили, а не в папке данных;
- удаление папки данных не удаляет сохранённые паки, но стирает черновик редактора,
  медиатеку и сохранение игры;
- при удалении установленного приложения данные в `%APPDATA%\quizmaster` сохраняются.

## 10. Горячие клавиши

| Клавиши | Где | Действие |
|---|---|---|
| Ctrl+S | редактор | сохранить пак |
| Ctrl+Shift+S | редактор | сохранить копию |
| Ctrl+O | редактор | открыть пак |
| Ctrl+N | редактор | новый пак |
| Ctrl+Enter | редактор | провести игру |
| F11 | игровой экран | полный экран / оконный режим |

## 11. Ограничения и правила

| Правило | Значение |
|---|---|
| участников в игре | не больше 40 |
| длина названия участника | до 60 символов |
| время вопроса | от 5 до 3600 секунд |
| стоимость вопроса | от 0 до 1000 баллов, дробные разрешены |
| «Частично» | всегда половина стоимости вопроса |
| раундов в паке | минимум один |
| вопросов в раунде | минимум один (последний вопрос очищается, а не удаляется) |
| режим игры | выбирается до начала игры |
| состав участников | можно менять только до начала игры |
| интернет | для создания паков и проведения игры не требуется |
