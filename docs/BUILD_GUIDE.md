# Установка окружения, запуск и сборка QuizMaster

Инструкция для того, кто впервые разворачивает проект на компьютере с Windows.
Все действия выполняются в папке проекта — той, где лежат файлы `INSTALL.bat`,
`START.bat`, `package.json` и папка `packs`.

Если вы получили уже готовый установщик `release\QuizMaster-1.2.0-Setup.exe`
и не собираетесь менять код, переходите сразу к разделу
[«Установка готового приложения»](#8-установка-готового-приложения).

## 1. Проверьте компьютер

| Что проверить | Как |
|---|---|
| Версия Windows | «Пуск» → «Параметры» → «Система» → «О системе». Нужны Windows 10 или Windows 11, разрядность 64 бита |
| Свободное место | не меньше 2 ГБ на диске с проектом (зависимости и кэш сборки занимают примерно 1,1 ГБ) |
| Интернет | нужен на шагах 2–3 и при первой сборке установщика; для игры не нужен |

Ожидаемый результат: компьютер соответствует таблице, в папке проекта есть `package.json`
и файлы `.bat`.

Если папки проекта ещё нет, сначала перенесите её — см.
[docs/TRANSFER_GUIDE.md](TRANSFER_GUIDE.md).

## 2. Установите Node.js LTS

1. Откройте в браузере `https://nodejs.org`.
2. Нажмите кнопку **LTS**. Скачается установщик `node-v…-x64.msi`.
3. Запустите скачанный файл и нажимайте «Next» («Далее»), ничего не меняя. Если появится
   запрос прав администратора, разрешите установку.
4. Дождитесь сообщения «Completed» / «Готово» и нажмите «Finish».

Проверка:

1. Нажмите `Win+R`, введите `cmd` и нажмите Enter — откроется командная строка.
2. Введите по очереди две команды:

   ```
   node -v
   npm -v
   ```

3. Ожидаемый результат: две строки с номерами версий, например `v24.21.0` и `11.19.0`.
   Подойдёт LTS-версия Node.js 20 или новее; проект проверен на Node.js 24.

Если вместо версии появляется «"node" не является внутренней или внешней командой»:

- закройте и снова откройте командную строку (после установки PATH обновляется не сразу);
- если не помогло — переустановите Node.js с параметрами по умолчанию и перезагрузите компьютер;
- повторите проверку.

## 3. Установите зависимости проекта

1. Откройте папку проекта в Проводнике.
2. Дважды щёлкните `INSTALL.bat`.

Что произойдёт: откроется окно консоли с заголовком «QuizMaster — установка зависимостей».
Скрипт проверит Node.js и npm, выведет их версии, создаст папку `.cache` внутри проекта
и выполнит `npm install`. Кэши npm и Electron остаются внутри папки проекта, а не в системных
каталогах.

Ожидаемый результат в конце:

```
============================================
  Готово! Зависимости установлены.
  Теперь запускайте START.bat
============================================
```

Время: примерно 3–10 минут при первом запуске (скачивается Electron). Нужен интернет.

Если появилось сообщение об ошибке:

| Сообщение | Что сделать |
|---|---|
| «[ОШИБКА] Node.js не найден» | вернуться к шагу 2 |
| «[ОШИБКА] npm не найден. Переустановите Node.js» | переустановить Node.js |
| «[ОШИБКА] В этой папке нет проекта QuizMaster» | запускать `INSTALL.bat` именно из папки проекта |
| «[ОШИБКА] npm install завершился с ошибкой» | проверить интернет, удалить папку `node_modules` и запустить `INSTALL.bat` снова; подробнее — [docs/troubleshooting.md](troubleshooting.md) |
| «Не удалось скачать Electron» | проверить интернет и свободное место, запустить `INSTALL.bat` снова |

## 4. Запустите приложение

1. В папке проекта дважды щёлкните `START.bat`.
2. В консоли появятся строки «Собираю приложение…» и «Запускаю QuizMaster…».
3. Через несколько секунд откроется окно «QuizMaster — редактор».

Ожидаемый результат: окно редактора с верхней панелью кнопок («Новый», «Открыть»,
«Сохранить как», «Сохранить», «▶ Провести игру»), слева — панель «Раунды» с одним раундом,
в центре — пустой вопрос.

Время: первый запуск после установки зависимостей — около 10–60 секунд (идёт сборка),
дальше быстрее. Интернет не нужен.

Важно:

- окно консоли не закрывайте во время работы — вместе с ним закроется приложение;
- для выхода закройте окна QuizMaster, дождитесь строки «QuizMaster закрыт» и закройте консоль;
- если папка `node_modules` отсутствует, `START.bat` сам запустит `INSTALL.bat`.

Если окно не появилось или показывает чёрный экран — см.
[docs/troubleshooting.md](troubleshooting.md), раздел «Окно не открывается или чёрный экран».

## 5. Режим разработки (для изменений интерфейса)

Нужен, если вы правите код и хотите видеть изменения без ручной пересборки.

1. Дважды щёлкните `START-DEV.bat`.
2. Скрипт соберёт main/preload, запустит сервер Vite на порту `5273` и откроет приложение.
3. Изменения файлов в `src/renderer` применяются сразу после сохранения файла. Изменения
   в `src/main`, `src/preload` и `src/shared` пересобираются автоматически и перезапускают
   окно приложения.
4. В режиме разработки дополнительно открываются инструменты разработчика (DevTools),
   а меню приложения остаётся стандартным.

Остановка: закройте окно приложения или нажмите Ctrl+C в консоли.

Если порт `5273` занят другой программой, Vite завершится с ошибкой — закройте лишний процесс
и запустите `START-DEV.bat` снова.

## 6. Соберите установщик

1. Убедитесь, что зависимости установлены (`INSTALL.bat` выполнялся, папка `node_modules` есть).
2. Дважды щёлкните `BUILD.bat`.

Что произойдёт: скрипт соберёт приложение (`npm run build`), затем запустит упаковку
установщика (`npm run dist`). При первой сборке скачиваются инструменты electron-builder —
нужен интернет и около 1 ГБ свободного места. Кэш инструментов остаётся в `.cache` внутри
проекта.

Ожидаемый результат:

```
============================================
  Готово!
  Установщик лежит в папке release:
  release\QuizMaster-1.2.0-Setup.exe
============================================
```

Папка `release` откроется в Проводнике автоматически.

Время: 5–10 минут при первой сборке, при повторных — быстрее.

Если появилось «[ОШИБКА] Не удалось собрать установщик» — проверьте интернет, свободное место
и что приложение QuizMaster не запущено (занятые файлы мешают упаковке). Подробнее —
[docs/troubleshooting.md](troubleshooting.md), раздел «Установщик не собирается».

## 7. Проверьте установщик и приложение

1. Запустите `release\QuizMaster-1.2.0-Setup.exe`.
2. Windows может показать предупреждение SmartScreen, потому что установщик не подписан
   цифровой подписью: нажмите «Подробнее» → «Выполнить в любом случае».
3. Установка занимает несколько секунд и идёт без вопросов: приложение ставится для текущего
   пользователя в `%LOCALAPPDATA%\Programs\QuizMaster`, права администратора не нужны.
   После установки QuizMaster запустится автоматически.
4. Если автоматически не запустилось — откройте QuizMaster с рабочего стола или из меню «Пуск».

Если установщик не запускается или антивирус его блокирует, есть резервный вариант:
распакуйте `release\QuizMaster-1.2.0-portable.zip` в любую папку (например
`D:\QuizMaster`) и запустите `QuizMaster.exe` из неё — установка при этом не требуется.

Проверка, что всё работает:

1. Открылось окно «QuizMaster — редактор».
2. Нажмите «Демо-паки» → у «Демо-квиз: Космос» нажмите «Открыть» — появится пак с двумя
   раундами и пятью вопросами.
3. Нажмите «▶ Провести игру» — откроются панель ведущего и игровой экран.
4. В панели ведущего добавьте одну команду и нажмите «Начать игру» — на игровом экране
   появится заставка раунда.
5. Меню «Справка» → «Версия 1.2.0» и «Открыть папку данных» — открывается `%APPDATA%\quizmaster`.

Ожидаемый результат: все пять пунктов выполняются без сообщений об ошибках.

## 8. Установка готового приложения

Если установщик уже собран (файл `release\QuizMaster-1.2.0-Setup.exe`) и нужно поставить
приложение на другой компьютер:

1. Перенесите файл установщика на этот компьютер.
2. Запустите его — установка пройдёт автоматически (см. шаг 7).
3. Запустите QuizMaster и выполните проверку из шага 7.

Node.js и интернет на этом компьютере не нужны. Установленная версия хранит данные
в `%APPDATA%\quizmaster` и не удаляет их при удалении приложения.

## 9. Что делать, если что-то не совпало

| Ситуация | Действие |
|---|---|
| На шаге 2 нет кнопки LTS или сайт не открывается | проверить интернет; скачать любую актуальную LTS-версию Node.js |
| На шаге 3 ошибка npm | [docs/troubleshooting.md](troubleshooting.md), «Не устанавливаются зависимости» |
| На шаге 4 окно не открылось | [docs/troubleshooting.md](troubleshooting.md), «Окно не открывается или чёрный экран» |
| На шаге 4 сообщение «Сборка не удалась» | удалить `node_modules` и выполнить `INSTALL.bat` заново |
| На шаге 6 сборка падает | [docs/troubleshooting.md](troubleshooting.md), «Установщик не собирается» |
| Установщик запускается, но антивирус его блокирует | [docs/troubleshooting.md](troubleshooting.md), «Антивирус блокирует» |

## 10. Полезные команды для проверки

Выполняются в командной строке из папки проекта.

| Команда | Что делает |
|---|---|
| `node -v` | показывает версию Node.js |
| `npm run typecheck` | проверяет типы TypeScript |
| `npm test` | юнит-тесты подсчёта баллов и статистики |
| `npm run build` | собирает приложение в папку `dist` |
| `npm run e2e` | запускает e2e-проверки на реальном Electron; нужны собранное приложение и рабочий стол Windows |
| `npm run dev` | то же, что `START-DEV.bat` |
| `npm run dist` | собирает установщик в `release` |

Проверка реального запуска приложения описана в [docs/build.md](build.md).
