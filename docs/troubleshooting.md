# Типовые ошибки и их решение

Документ помогает найти причину и порядок действий, если что-то не работает. Ошибки
сгруппированы по этапам: запуск, редактор, игра, медиа, паки, восстановление, сборка.

Если сообщение об ошибке есть на экране, найдите его в тексте ниже по точной формулировке.
Для решения пригодятся:

- окно консоли, из которого запускалось приложение (`START.bat`): в нём печатаются ошибки сборки;
- папка данных `%APPDATA%\quizmaster` (меню «Справка» → «Открыть папку данных»);
- файлы `INSTALL.bat`, `START.bat`, `BUILD.bat` в папке проекта.

## 1. Ошибки Node.js и окружения

### «[ОШИБКА] Node.js не найден», «[ОШИБКА] Не найден Node.js»

Сообщение появляется в `INSTALL.bat`, `START.bat`, `START-DEV.bat` или `BUILD.bat`.

Причина: Node.js не установлен или командная строка его не видит.

Что делать:

1. Откройте `https://nodejs.org` и установите версию **LTS** (кнопка «LTS»), нажимая «Далее»
   без изменений.
2. Перезапустите скрипт `.bat`.
3. Если сообщение повторяется — откройте командную строку (`Win+R` → `cmd`) и выполните
   `node -v`. Если версия не выводится, перезагрузите компьютер и проверьте снова.
4. Если и после перезагрузки не выводится — переустановите Node.js с параметрами
   по умолчанию.

Подробная инструкция — [docs/BUILD_GUIDE.md](BUILD_GUIDE.md), шаг 2.

### «[ОШИБКА] npm не найден. Переустановите Node.js»

Причина: установка Node.js повреждена или npm не попал в PATH.

Что делать: переустановите Node.js LTS, затем запустите `INSTALL.bat` снова.

### «[ОШИБКА] В этой папке нет проекта QuizMaster»

Причина: `.bat` запущен не из папки проекта (например, из архива или из папки `docs`).

Что делать: откройте папку, где лежат `package.json` и `INSTALL.bat`, и запустите скрипт
из неё. Если проект ещё не перенесён — см. [docs/TRANSFER_GUIDE.md](TRANSFER_GUIDE.md).

### «[ОШИБКА] Не установлены зависимости. Сначала запустите INSTALL.bat»

Причина: нет папки `node_modules` (первый запуск или папку удалили).

Что делать: запустите `INSTALL.bat`, дождитесь надписи «Готово! Зависимости установлены»,
затем повторите действие.

## 2. Не устанавливаются зависимости

### `npm install` завершился ошибкой

Причины: нет интернета, обрыв загрузки, нехватка места, повреждённый кэш, блокировка
антивирусом.

Что делать по порядку:

1. Проверьте интернет: откройте в браузере `https://nodejs.org`.
2. Проверьте свободное место: нужно около 2 ГБ.
3. Удалите папку `node_modules` в папке проекта.
4. Запустите `INSTALL.bat` снова.
5. Если ошибка повторяется — посмотрите текст ошибки в консоли. Сообщения вида `ETIMEDOUT`,
   `ECONNRESET`, `ENOTFOUND` означают проблему сети; `EACCES`, `EPERM` — блокировку файлов
   антивирусом или правами.

### «[ОШИБКА] Не удалось скачать Electron. Проверьте интернет и повторите»

Причина: не скачался сам Electron (установка npm прошла, а загрузка программы окон — нет).

Что делать:

1. Проверьте интернет и свободное место.
2. Запустите `INSTALL.bat` снова: он дозагрузит Electron в `node_modules\electron\dist`.
3. Если сеть ограничена (корпоративная), попробуйте другую сеть или настройте прокси
   для npm.

### Нет интернета, а проект нужно запустить

Причина: интернет нужен только для установки зависимостей и сборки. Если папка
`node_modules` уже есть, приложение запускается без интернета. Если папки нет — установить
зависимости без интернета нельзя: перенесите проект вместе с уже установленной папкой
`node_modules` либо используйте готовый установщик на другом компьютере.

## 3. Окно не открывается или чёрный экран

### После запуска `START.bat` окно не появилось

Порядок проверки:

1. Посмотрите на окно консоли. Если идёт «Собираю приложение…», подождите: запуск занимает
   до 60 секунд.
2. Если в консоли есть «[ОШИБКА] Сборка не удалась», удалите папку `node_modules`, запустите
   `INSTALL.bat`, затем `START.bat`.
3. Если консоль пуста и окна нет — подождите 10–20 секунд; при первом запуске сборка дольше.
4. Закройте все окна приложения и запустите `START.bat` снова.

### Окно открылось, но показывает чёрный экран

1. Подождите несколько секунд: идёт загрузка интерфейса.
2. В меню окна выберите «Вид» → «Обновить».
3. Если не помогло, закройте приложение и запустите снова.
4. Если чёрный экран повторяется на всех окнах — проверьте, что обновлены драйверы
   видеокарты. Как временная мера помогает запуск с отключённым аппаратным ускорением:
   в командной строке из папки проекта выполните

   ```
   node_modules\electron\dist\electron.exe . --disable-gpu
   ```

   Команду запускайте из папки проекта после того, как приложение хотя бы раз собиралось
   (`START.bat`). Для установленной версии запустите `QuizMaster.exe --disable-gpu`
   из папки установки.

### Окно закрылось, а игра продолжается

Причина: окна работают независимо.

Что делать:

- закрылось игровое окно — нажмите «Игровой экран» в панели ведущего;
- закрылся редактор — во время игры он не нужен; после итогов его откроет кнопка
  «Новая игра», а если игра не запущена — кнопка «Открыть редактор» в панели ведущего;
- закрылась панель ведущего — открыть её заново кнопкой нельзя: закройте остальные окна
  QuizMaster, запустите приложение снова и восстановите игру (раздел 6);
- если закрыты все окна, приложение завершается — запустите его снова и восстановите игру.

### «Что-то пошло не так» вместо интерфейса

Причина: ошибка отрисовки окна (сбой в коде интерфейса или повреждённое состояние).

Что делать:

1. Нажмите «Перезапустить окно».
2. Если ошибка повторяется — закройте приложение, запустите снова. Черновик пака
   восстановится из автосохранения.
3. Если ошибка возникает при открытии конкретного пака, попробуйте другой пак: возможно,
   файл пака повреждён (раздел 5).

## 4. Не слышно звук, не играет видео

### Видео не запускается

1. Проверьте, что файл открывается в проигрывателе Windows.
2. Убедитесь, что формат поддерживается надёжно: **MP4 (H.264/AAC)** или **WEBM**.
   Форматы MOV и MKV могут не проигрываться из-за отсутствия нужного кодека
   в приложении.
3. Если файл в неподходящем формате, перекодируйте его в MP4 любым конвертером и добавьте
   заново кнопкой «Заменить».
4. Сохраните пак и перезапустите игру: изменения пака не применяются к уже запущенной игре.

Если вместо видео написано «Видео недоступно», файл не найден или не читается: добавьте
видео к вопросу повторно и сохраните пак.

### Не слышно аудио

1. Проверьте громкость Windows и микшер громкости: у приложения QuizMaster может быть
   отдельный уровень.
2. Проверьте, что файл воспроизводится в проигрывателе Windows.
3. Используйте надёжные форматы: **MP3** или **WAV**. Форматы M4A, FLAC, AAC, OGG зависят
   от кодека.
4. Если вместо плеера написано «Аудио недоступно», файл не найден или не читается:
   добавьте его повторно и сохраните пак.

### Звук был, но пропал после паузы

Причина: пауза игры приостанавливает видео и аудио. После нажатия «Продолжить» воспроизведение
продолжается с того же места.

Что делать: нажмите «Продолжить». Если звук не вернулся, нажмите на игровом экране кнопку
воспроизведения в аудиоплеере или заново откройте вопрос.

### Медиа не попали в пак

Причина: файл медиа не найден в медиатеке при сохранении.

Что делать:

1. Откройте вопрос в редакторе и проверьте, что предпросмотр медиа отображается.
2. Если медиа нет — добавьте файл заново кнопкой «Добавить» или «Заменить».
3. Сохраните пак. При сохранении читайте сообщения: «Не найден файл медиа … — он не будет
   добавлен в пак».

## 5. Повреждённый пак

### «Повреждённый пак: внутри архива нет manifest.json»

Причина: файл `.quizpack` не является паком QuizMaster, повреждён при копировании или
переименован из другого архива.

Что делать:

1. Найдите другую копию файла (например, резервную).
2. Если пак получен от другого человека, запросите файл заново: при передаче через мессенджер
   или при неполной загрузке архив мог обрезаться.
3. Не пересохраняйте пак сторонними архиваторами.

### «Повреждённый пак: не удалось прочитать описание игры»

Причина: внутри архива есть `manifest.json`, но его содержимое повреждено.

Что делать: запросите файл заново или восстановите из резервной копии. Если пак создавался
в QuizMaster, проверьте диск на ошибки: повреждение могло произойти при записи.

### «Пак создан в более новой версии QuizMaster — часть данных может не отображаться»

Причина: пак сохранён более новой версией приложения.

Что делать: обновите QuizMaster до более новой версии. Пак при этом открывается, но часть
полей может не отображаться.

### «Файл медиа «…» повреждён (не совпала контрольная сумма)»

Причина: файл внутри архива изменился или повредился. Пак открывается, но этот медиафайл
будет пропущен.

Что делать:

1. Откройте пак, проверьте замечания в сообщении.
2. Добавьте повреждённый файл к вопросу заново и сохраните пак кнопкой «Сохранить как» —
   будет создан исправный архив.
3. Если пак получен извне, запросите файл заново.

### «В паке отсутствует файл медиа «…» / «Медиа «…» не найдено в паке»

Причина: в манифесте перечислен файл, которого нет в архиве.

Что делать: пак откроется, вопрос покажется без этого медиа. Добавьте файл заново и сохраните
пак. Если это чужой пак — запросите исправную копию.

### Как снизить риск повреждения

- не редактируйте `.quizpack` сторонними программами;
- сохраняйте пак кнопкой «Сохранить как» перед переносом на другой компьютер;
- храните резервную копию важных паков на другом носителе.

## 6. Игра не восстановилась

### Баннер «Найдена незавершённая игра» не появился

Порядок проверки:

1. Убедитесь, что игра была прервана не в лобби и не после финала: лобби не сохраняется,
   а после показа итогов сохранение удаляется автоматически.
2. Запустите приложение, откройте в редакторе пак, которым играли, и нажмите «▶ Провести игру» —
   откроется панель ведущего, в которой появляется баннер восстановления. Если редактор
   предложит сохранить пак, сохраните его: это нужно только для открытия панели ведущего.
3. Проверьте файл сохранения: меню «Справка» → «Открыть папку данных» → папка `sessions`.
   Файл называется `current.json`. Если его нет — восстанавливать нечего.
4. Убедитесь, что приложение запускается от того же пользователя Windows: папка данных
   у каждого пользователя своя.

### Нажал «Восстановить», но игра началась не с того места

Причина: сохранение обновляется после изменений и во время таймера примерно раз в 3 секунды.
Могло сохраниться состояние на пару секунд раньше сбоя.

Что делать: продолжите игру с восстановленного места. Баллы, участники, режим и пропущенные
вопросы сохраняются; остаток таймера может отличаться на несколько секунд — это нормально.

### «Сохранённая игра не найдена»

Причина: между открытием баннера и нажатием «Восстановить» файл сохранения удалили или
приложение перезапустили с очисткой данных.

Что делать: запустите игру заново из редактора. Восстановить баллы в этом случае нельзя.

### После восстановления игра стоит на паузе

Это нормальное поведение: восстановленная игра помечается как приостановленная, чтобы ведущий
проверил состояние. На экране вопроса или заставки раунда нажмите «Продолжить», чтобы запустить
отсчёт; на экране итогов раунда пауза не отображается, работать с баллами можно сразу.

## 7. Антивирус блокирует

### Windows не даёт запустить установщик

Причина: `QuizMaster-1.3.2-Setup.exe` не подписан цифровой подписью, поэтому SmartScreen
показывает предупреждение.

Что делать:

1. Нажмите «Подробнее» в окне предупреждения.
2. Нажмите «Выполнить в любом случае».
3. Если кнопки нет — проверьте, что файл получен из доверенного источника и не повреждён.

### Установщик не устанавливает приложение

Установка идёт в один клик в `%LOCALAPPDATA%\\Programs\\QuizMaster` без прав администратора.
Если окно установщика закрывается, а приложение не появилось, есть запасной вариант —
портативная версия без установки:

1. Возьмите файл `release\\QuizMaster-1.3.2-portable.zip` (создаётся вместе с установщиком).
2. Распакуйте его в отдельную папку, например `QuizMaster`.
3. Запустите `QuizMaster.exe` из этой папки.

Портативная версия работает так же, только без ярлыков и пункта удаления в «Программах и компонентах».

### Антивирус удаляет или блокирует файлы проекта

Причина: антивирус может проверять `node_modules`, `dist` и скачиваемый Electron.

Что делать:

1. Посмотрите журнал защиты антивируса: что именно заблокировано.
2. Если заблокирован `node_modules\electron\dist\electron.exe`, восстановите его из карантина
   или запустите `INSTALL.bat` снова, добавив папку проекта в исключения.
3. Не отключайте защиту полностью: достаточно добавить в исключения папку проекта.

### Установщик не запускается из-за блокировки

Что делать: проверьте «Свойства» файла: если стоит отметка «Разблокировать», поставьте её
и нажмите «ОК», затем запустите установщик снова.

## 8. Установщик не собирается

### «[ОШИБКА] Не удалось собрать установщик»

Порядок проверки:

1. **Свободное место.** Нужно около 1 ГБ: проверьте диск.
2. **Интернет.** Первая сборка скачивает инструменты electron-builder (NSIS и вспомогательные
   файлы). Без интернета сборка не пройдёт.
3. **Запущенное приложение.** Закройте окна QuizMaster и окно консоли `START.bat`: занятые
   файлы мешают упаковке.
4. **Открытые папки.** Закройте окна Проводника, открытые в `dist` и `release`.
5. **Повторная попытка.** Удалите папку `release` и запустите `BUILD.bat` снова.
6. **Текст ошибки.** Посмотрите вывод консоли: если ошибка связана с загрузкой (сеть,
   `ETIMEDOUT`, `ECONNRESET`), повторите попытку позже или через другую сеть.
7. **Антивирус.** Если антивирус блокирует запись в `release`, добавьте папку проекта
   в исключения.

### Сборка проходит, но файла `release\QuizMaster-1.3.2-Setup.exe` нет

1. Проверьте, что сборка завершилась сообщением «Готово!».
2. Откройте папку `release` вручную и проверьте, что файл `QuizMaster-1.3.2-Setup.exe`
   существует и его размер не нулевой.
3. Если файла нет или он неполный — удалите папку `release` и повторите `BUILD.bat`.

### Сборка падает, хотя типы проверяются отдельно

Причина: `npm run build` и `npm run dist` не проверяют типы TypeScript: они запускают
esbuild и Vite, которые удаляют типы при сборке. Ошибка в сборке — это ошибка импорта,
синтаксиса или упаковки, а не типов.

Что делать:

1. Посмотрите полный текст ошибки в консоли: в нём указан файл и строка.
2. Отдельно проверьте типы командой `npm run typecheck` в командной строке из папки проекта
   и исправьте найденные ошибки.
3. Удалите папку `node_modules` и выполните `INSTALL.bat` заново, если ошибка похожа
   на отсутствующий модуль.
4. Повторите `BUILD.bat`.

## 9. Редактор и паки

### Пак не сохраняется

Причины: нет прав на запись в выбранную папку, мало места, файл открыт в другой программе,
недопустимое имя.

Что делать:

1. Выберите другую папку для сохранения (например, «Документы»).
2. Проверьте свободное место на диске.
3. Закройте программы, которые могут держать файл `.quizpack` открытым.
4. Используйте простые имена файлов без символов `\ / : * ? " < > |`.

Носитель только для чтения (например, защищённая от записи флешка) также не позволит
сохранить пак.

### «Нельзя начать игру: В паке нет ни одного раунда / вопроса»

Причина: пак пустой.

Что делать: добавьте хотя бы один раунд и вопрос, затем снова нажмите «Провести игру».

### «Игра запускается, но проверьте пак: Без текста вопроса… / Без правильного ответа…»

Причина: часть вопросов заполнена не полностью. Игра стартует, но такие вопросы выглядят
пустыми на экране.

Что делать: заполните тексты и правильные ответы, сохраните пак и запустите игру заново.

### Пропал черновик редактора

Причина: черновик хранится в `%APPDATA%\quizmaster\drafts\draft.json` и очищается после
успешного сохранения пака.

Что делать:

1. Если пак сохранялся в файл, откройте его кнопкой «Открыть».
2. Проверьте папку данных: если `draft.json` есть, перезапустите приложение — черновик
   загрузится автоматически.
3. Если черновик утерян, восстановить его нельзя; сохраняйте важные паки в файл перед
   закрытием.

### «В паке должен остаться хотя бы один раунд»

Это ограничение, а не ошибка: пак без раундов невозможен. Добавьте новый раунд и удалите
старый.

## 10. Игра и баллы

### «Начать игру» неактивна

Причина: не добавлен ни один участник.

Что делать: введите название команды или участника и нажмите «Добавить» (или Enter).

### «Добавьте хотя бы одну команду»

Причина: к моменту старта список участников пуст (например, после удаления всех участников).

Что делать: добавьте участника и нажмите «Начать игру» снова.

### «Слишком много команд (максимум 40)»

Добавлено 40 участников — предел. Удалите лишних (кнопка ✕ в лобби) или проведите игру
в несколько этапов.

### Баллы не вводятся

1. Сначала щёлкните по ячейке таблицы: блок быстрого ввода относится к выбранной ячейке.
2. Введите число и нажмите «Применить» или Enter. Дробное значение вводится через запятую
   или точку: `2,5`.
3. Отрицательные баллы не принимаются: появится сообщение «Баллы не могут быть
   отрицательными».
4. Если появилось «Введите число, например 2,5», в поле нет числа.

### Таймер стоит на месте

Возможные причины:

- игра на паузе: нажмите «Продолжить»;
- ответ показан: показ ответа останавливает таймер, нажмите «Пауза», затем «Продолжить»;
- открыта заставка раунда: таймер запускается при открытии первого вопроса;
- время вышло: таймер показывает 00:00, следующий вопрос открывает ведущий.

### «Показать ответ» неактивна

Кнопка работает только в фазе вопроса. Откройте первый вопрос кнопкой «Начать раунд →».

### Игровой экран не на втором мониторе

1. В Windows включите режим «Расширить эти экраны»: «Параметры» → «Система» → «Дисплей».
2. В панели ведущего в лобби выберите нужный монитор в блоке «Экраны».
3. Если игровое окно уже открыто, нажмите «Игровой экран», затем «Полный экран».

Во время игры список мониторов недоступен: монитор выбирается до начала игры.

### На проекторе видна панель ведущего

Причина: перепутаны окна. Панель ведущего — для ведущего (обычно на ноутбуке), игровой
экран — для участников (проектор или второй монитор).

Что делать: закройте лишнее окно или перенесите игровое окно на второй монитор в лобби,
нажав «Открыть игровое окно».

## 11. Что приложить при обращении за помощью

1. Текст ошибки: полностью, из окна консоли или из сообщения в приложении.
2. Шаг, на котором возникла ошибка, и что делали перед этим.
3. Версию Windows и версию Node.js (`node -v` в командной строке).
4. Скриншот окна с ошибкой.
5. При проблеме с паком — сам файл `.quizpack`, если его можно передать.
